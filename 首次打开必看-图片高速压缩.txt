先别慌
你好！这是「星 TAP 图片高速压缩」v4.1.0，完全免费分享。
因为没做付费代码签名（Authenticode），Windows 的 SmartScreen / 杀毒软件第一次打开几乎必定拦你一下——这很正常，不是病毒，也不会动你任何文件，只是「不认识这个发布者」所以多问一句。你只要放行这一次，以后就顺畅了。

怎么运行
1. 把压缩包整个解压到一个文件夹（比如桌面新建个「图片压缩」文件夹）。
2. 双击里面的「图片高速压缩.exe」就能用，不用安装、不用联网。
3. 它是绿色单文件版：整个程序就那一个 exe，不往系统塞任何东西，用完直接删文件夹就行。
4. 默认输出目录为 `compressed/`，不污染源文件所在目录。

首次被拦怎么办（三选一）
方法 A（最常见）：弹窗点「更多信息」→ 再点「仍要运行」。
方法 B：右键「图片高速压缩.exe」→ 属性 → 底部「安全」那里勾「解除锁定」→ 确定，然后再双击。
方法 C（被直接删了）：去 Windows 安全中心 → 病毒和威胁防护 → 保护历史记录 → 找到它 → 选「允许」或「还原」，再走方法 A/B。

支持的系统 / 小贴士
- 支持 Windows 10、Windows 11（含比较老的配置），单文件 0 依赖，不用装任何运行库（VC++ 什么的都不用装）。
- 拖入照片即可批量压缩，支持 JPG / PNG / WEBP 等常见格式，可选导出目录和格式。
- RAW 格式（CR3 / NEF / ARW / DNG 等）仅在 macOS 版支持；Windows 版遇到 RAW 会明确提示，请在 Mac 上处理或先转 JPG/PNG。
- 新增 --capabilities 能力探测（AI 专用）：`图片高速压缩.exe --capabilities`
- 新增 --dry-run 预演模式：先扫文件不压缩，安全确认后再正式处理。
- 新增 --include / --exclude 文件筛选模式，支持通配符：`--include "*.jpg,*.png"`。
- 新增摄影级优化：`--enable-sharpening` 智能锐化 / `--color-space srgb` 色彩空间转换。
- 命令行用法：`图片高速压缩.exe "C:\我的照片\a b.jpg"`（路径含空格必须加引号！）。
  给 AI/脚本最稳妥：用 `--json` 从 stdin 传路径数组，彻底绕开 shell 分词。
  详细用法：`图片高速压缩.exe --help`
